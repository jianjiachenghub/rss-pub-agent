Host B: There is also a fascinating counterintuitive case from the engineering world. While optimizing case folding for its 480-terabyte code search system, GitHub removed the logic that exited early when no conversion was needed and replaced it with a branchless scan. ASCII throughput exceeded 45 GiB per second—15 times faster than the naïve approach.

Host A: Doing fewer steps does not necessarily make something faster. What matters is whether the CPU can execute the work smoothly through vectorization. The accompanying Rust library, casefold, also handles Unicode with a compact 1,776-byte structure. Low-level optimizations like these ultimately translate directly into lower costs for indexing code at scale.
